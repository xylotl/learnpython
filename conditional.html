5  Conditionals and Conditional Statements

5.1 Conditionals

Conditionals are much like the type of statements you’ll see in math. (1 < 5, 7 =>3) The power it holds when we use them in python is that we can compare variables to numbers through checking if it’s greater than, less than or equal. Equal signs also work for strings and chara to check if they’re equivalent. What may surprise you is that less than and greater than also work for chars. In reality, chars are actually just assigned numbers, these are deemed their ASCII values. These never change, so you can check if '%' < 'A'. An ASCII table is included below for your reference.

In python, we can check if a data type is equal by using ==.

The point of conditionals is that by comparing two data types, a boolean will be produced, telling you whether rhe conditional is true or false. This is why it’s called a conditional, because it’s a condition it must pass.

magicNumber = 6
magicString = "Magic!"
print(f"Is magicNumber < 4?  {magicNumber < 4}")
print(f"Does magicString == 'Magic!'? {magicString == 'Magic!'}")
Is magicNumber < 4?  False
Does magicString == 'Magic!'? True

Logic

Conditionals and booleans are a lot more complex than originally discussed. This involves something called logic. You may have heard logic used in other situations, like calling someone’s argument or perspective illogical. Logic in this context,philosophy, is actually the same logic we use in mathematics and respectively, programming.

NoteIf you want to know more

Formal logic is a whole lot more complex than what I’ll briefly discuss, and if you’re interested you may research it yourself.

Logic, as we’ll use it primarily involves use of the phrases and, or and not. In other languages, they use symbols to represent these, but in Python, we just use the words. These are used mainly with conditionals and result in a boolean. They check both the left-hand and right-hand side of itself. For and, it checks if both statements are True. For or it checks if at least one of the statements are True. For not, it simply produces the opposite of the boolean(remember each condition results in a boolean).

(True Condition) and ( True Condition) = True
(False Condition) and ( True Condition) = False
(False Condition) and ( False Condition) = False

(False Condition) or ( True Condition) = True
(True Condition) or ( True Condition) = True
(False Condition) or ( False Condition) = False

not (False Condition) = True
not (True Condition) = False

This can get a lot more complex with even more conditions, however it’d be easiest to remember both and and or only evaluate between two conditions, while not only evaluates one. So if you have more than one, break it down into brackets to make it clearer what is being evaluated, making it easier for you and others to understand!

print((magicNumber < 4) and (magicString == 'Magic!'))
print((magicNumber < 4) or (magicString == 'Magic!'))
print(not (magicNumber < 4))
False
True
True

This can get a little bit confusing, so let’s run down what the above code did.

In the first line, it checked whether magicNumber is less than 4 and magicString is the same as the string ‘Magic!’. Even though magicString does equal ‘Magic!’, magicNumber isn’t less than 4, so it is False.

In the second line, it checked whether either magicNumber is less than 4 or magicString is the same as the string ‘Magic!’. MagicNumber not being less than 4 doesn’t matter, as it’s checking whether at least one of the conditionals are True. MagicString == ‘Magic!’ results in True, therefore the entire condition is True.

In the third line, it is simpler as it is just checking if magic number is less than 4. Since it isn’t, it resolves to False, and the not in front negates that False to True.
